# O.K.P — Oru Kalyanam Pole

A multi-page static wedding-event website.

## Pages
Home, Our Story, Programme, Teams, Wedding House, Food, Gallery, RSVP.

## Run
Open `index.html` in a browser.

## Before publishing
1. Replace placeholder text/names.
2. Add real event date and venue.
3. Replace gallery placeholder blocks with event photos.
4. Connect RSVP form to Google Forms/Formspree or a backend.
5. Upload the folder to Netlify, Vercel, GitHub Pages, or your hosting provider.

## Design
Old-school Malabar wedding invitation / family album aesthetic with a 2000s-inspired editorial feel.
